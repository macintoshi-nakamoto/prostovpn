# ProstoVPN Bot

Телеграм-бот подписки [@myprostovpn_bot](https://t.me/myprostovpn_bot).

Аккаунты, подписки и платежи бот **не хранит у себя** — он работает с панелью
`prostovpn.cc` через её API. Логин и пароль одни и те же на сайте, в приложении
и в боте: где бы человек ни зарегистрировался, он войдёт везде.

## Где что живёт

| Данные | Где хранятся |
|---|---|
| учётки, подписки, платежи, тарифы | панель (`/opt/prosto-vpn`, `panel.db`) |
| сессии Telegram, обращения в поддержку | база бота (`database/database.db`) |

Панель отвечает боту двумя API:

* клиентский `/api/v1` — вход, кабинет, смена пароля (тот же, что у приложения);
* админский `/api/admin` — регистрация и продление после оплаты.

Регистрация идёт админским методом, а не «регистрацией с сайта»: та ограничена
тремя учётками с одного IP в сутки, а у бота адрес один на всех.

## Запуск

Боевой запуск — служба на сервере рядом с панелью:

```bash
systemctl status prosto-bot
```

Локально:

```bash
venv\Scripts\python.exe app.py
```

Проверка без Telegram (тексты, клавиатуры, база, живые тарифы из панели):

```bash
venv\Scripts\python.exe selfcheck.py
```

## Настройки (.env)

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен бота из @BotFather |
| `BOT_USERNAME` | имя бота без «@» — из него собирается реферальная ссылка `t.me/<имя>?start=ref<id>` |
| `ADMIN_IDS` | ID администраторов через запятую — им приходят обращения и оплаты (`/myid` в боте) |
| `PANEL_URL` | адрес панели: на сервере `http://127.0.0.1:8000`, снаружи `https://prostovpn.cc` |
| `PANEL_ADMIN_LOGIN`, `PANEL_ADMIN_PASSWORD` | доступ к админскому API; на сервере берутся из `.env` панели |
| `SIGNUP_PLAN` | тариф новых учёток из бота, по умолчанию `trial` |
| `STARS_RATE` | сколько звёзд за рубль цены тарифа; `1.0` — звезда равна рублю, цены как на сайте |
| `PROVIDER_TOKEN` | оплата картой внутри бота; пусто — только Telegram Stars |
| `SITE_URL` | ссылка на сайт в разделе «О сервисе» |
| `GUIDE_URL` | инструкция по установке: кнопка под «Наш канал» и ссылка на экране ключа для iPhone |

## Экраны

1. **Старт** — анимация, кнопка «Личный кабинет» и «О сервисе». Пока человек не
   вошёл, остальные разделы закрыты — их держит `middlewares/auth.py`.
2. **Личный кабинет** — вход или регистрация. Пароли бот не хранит и не
   проверяет: этим занимается панель. Сообщения с паролем удаляются из чата,
   после 5 неудачных попыток вход в боте закрывается на 10 минут.
3. **Кабинет** — логин, тариф, срок, остаток трафика, устройства. Кнопки:
   продлить, платежи, пароль, «Обход РУ-сервисов», поддержка. У людей с
   iPhone добавляется «Ключ для iPhone».
   * **Обход РУ-сервисов** — файл раздельного туннелирования из панели:
     банки и госуслуги ходят мимо VPN. Нужен только на iPhone, и экран
     говорит об этом первой строкой: в приложениях ProstoVPN для Windows,
     Android и macOS список уже внутри. Бот присылает файл документом, а не
     ссылкой: ссылку телефон открывает браузером, и вместо файла человек
     получает список доменов текстом на экране. Файл обновляется в панели,
     бот всегда отдаёт последнюю версию.
   * **Ключ для iPhone** — приложения под iOS нет, человек подключается
     через AmneziaVPN. Ключей столько, сколько устройств в тарифе (один пир
     нельзя поделить между телефонами), поэтому каждый уходит отдельным
     сообщением моноширинным блоком — нажатие копирует ссылку целиком.
4. **Тарифы и оплата** — сначала способ оплаты (Telegram Stars работает,
   СБП и криптовалюта помечены «скоро»), затем список тарифов из панели с
   ценами как на сайте. Звезда равна рублю. После оплаты бот продлевает
   подписку в панели и записывает платёж в её кассу; дни складываются.
5. **Поддержка** — частые проблемы с коротким решением, свободное обращение,
   список своих обращений. Ответ администратора: `/reply НОМЕР текст`.

## Цвета кнопок

Механика та же, что в `HeleketBot`: `style` у `InlineKeyboardButton` и иконка
`icon_custom_emoji_id`. Telegram принимает ровно четыре стиля — они собраны в
`keyboards/ui.py`:

| Стиль | Цвет | Где |
|---|---|---|
| `success` | зелёный | тарифы, продление, оплата |
| `danger` | красный | назад, отмена, выход |
| `default` | серый | всё остальное |

Цветных кнопок мало намеренно: цвет отмечает действие, а не украшает экран.
Иконки — из набора [LedScreenEmoji](https://t.me/addemoji/LedScreenEmoji),
идентификаторы собраны в `keyboards/ui.py`.

Если Telegram не пропустит премиум-эмодзи на конкретном токене, `utils/render.py`
перерисует экран обычными.

## Выкладка

```bash
rsync -a --exclude venv --exclude .env --exclude database ./ root@103.114.43.45:/opt/prosto-bot/
ssh root@103.114.43.45 'systemctl restart prosto-bot'
```

После замены анимаций — прогрев, иначе первый заход оплатит выгрузку файла:

```bash
ssh root@103.114.43.45 'cd /opt/prosto-bot && ./venv/bin/python warmup.py'
```

Прогрев выгружает каждый файл в Telegram один раз и запоминает `file_id`
(ключ — путь плюс размер, замена файла сбрасывает старый). Дальше экраны
уходят за сотые доли секунды. Если Telegram ответил `Gateway Timeout` —
повторите запуск позже, прогрев продолжит с недостающих.

Служба: `deploy/prosto-bot.service` → `/etc/systemd/system/`. Логи —
`journalctl -u prosto-bot -f`.

Аватар бота: `avatar.py` шлёт `setMyProfilePhoto`. Метод у Telegram есть, но
отвечает `Gateway Timeout` даже на килобайтную картинку, поэтому аватар
ставится вручную через @BotFather.

## Письма вдогонку (utils/drip.py)

Бот пишет первым тем, кто остановился на полпути. Обход раз в полчаса,
первый — через три минуты после старта службы.

| повод | кому | что делает |
|-------|------|------------|
| `signup` | зашёл в бота и за сутки не завёл аккаунт | обещает 20 дней; начислит регистрация |
| `idle` | аккаунт есть, ни одного рукопожатия | дарит дни сразу, добивая остаток до 20 |
| `renew` | подписка кончается (≤3 дней) | предлагает продлить, обещает 7 дней сверху |

Каждое письмо уходит один раз — таблица `nudges`, ключ «человек + повод».
Продление бот замечает по дате окончания: в момент письма она записывается
в `expires_snapshot`, и если в следующий обход дата выросла, значит оплата
прошла — неделя начисляется сама.

Проверить, кому что уйдёт, не отправляя: `/drip` у администратора
(`/drip go` — выполнить прямо сейчас). Ставки — `GIFT_DAYS`, `RENEW_AT`,
`RENEW_BONUS` в начале `utils/drip.py`.

Видео писем: `assets/gift20.mp4` и `assets/renew.mp4`, оба без звуковой
дорожки — Telegram показывает их как гифку.

## Заморозка подписки

Кнопка в кабинете бота (`handlers/cabinet.py`, callback'и `freeze` /
`freeze:yes` / `resume`). Дни на паузе не тратятся, VPN на это время
отключается. Правила — на стороне панели: бот только показывает
`account.freeze` (можно ли, почему нельзя, сколько в запасе) и зовёт
`panel.freeze()` / `panel.resume()`. Пауза доступна только на оплаченном
тарифе — пробные и подарочные дни морозить нельзя.

Письма вдогонку замороженных не трогают: у них часы стоят, и «продлите,
осталось три дня» было бы неправдой.

## Боты-переходники

Рекламные боты, у которых один экран и одна кнопка «Перейти», живут
отдельной службой: `/opt/prosto-gate` (`gate.py`, `prosto-gate.service`),
токены в `tokens.txt` по одному в строке. Кнопка ведёт на промо-ссылку
основного бота, адрес — `GATE_TARGET` в `/opt/prosto-gate/.env`. Сводка по
переходам: `/stats` у администратора в любом из этих ботов.

## Структура

```
app.py              точка входа, сборка роутеров
assets/*.mp4        анимации: свой файл на каждый экран, см. utils/assets.py
config/settings.py  токен, админы, панель, темы поддержки
database/           сессии Telegram и обращения
handlers/           start, auth, cabinet, plans, payments, support, admin, common
keyboards/          ui.py — стили и иконки, menus.py — клавиатуры
middlewares/auth.py доступ к разделам только после входа
utils/panel.py      клиент панели: тарифы, вход, кабинет, продление
utils/render.py     показ экранов, анимация, запасные эмодзи
utils/drip.py       письма вдогонку: регистрация, первое подключение, продление
```

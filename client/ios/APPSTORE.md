# iOS: что сделано и что осталось до App Store

Документ честный: часть работы физически невозможно выполнить без macOS, и
здесь прямо написано, какая именно.

## Чем было и чем стало

Приложение было **макетом**: подключение имитировалось таймером, вход —
гостевым режимом и ключами `vpn://`, страны захардкожены в файле. Ни
NetworkExtension, ни entitlements не существовало — то есть туннеля не было
вовсе, при полностью нарисованном интерфейсе.

Добавлено то, без чего это не VPN-приложение:

| Файл | Что делает |
|------|-----------|
| `ProstoVPN/PanelAPI.swift` | Клиент панели `/api/v1/*`: вход, страны, подписка, обновления. Тот же контракт, что у Android и десктопа |
| `ProstoVPN/Keychain.swift` | Токен и конфиг туннеля в связке ключей, а не в UserDefaults |
| `ProstoVPN/TunnelController.swift` | Системный профиль VPN: завести, поднять, снять, читать статус |
| `ProstoVPNTunnel/PacketTunnelProvider.swift` | Само расширение туннеля: разбор конфига, сетевые настройки, мост к движку |
| `ProstoVPN/LiquidGlass.swift` | Стекло и анимации, не роняющие кадры |
| `*.entitlements`, `PrivacyInfo.xcprivacy` | Права на туннель и манифест приватности |

Убрана утечка: приложение спрашивало геолокацию узла у `ip-api.com` открытым
HTTP, вынося в сеть адрес узла, к которому человек собирается подключиться.
Та же дыра была в десктопном клиенте и убрана там по той же причине.

## Чего я сделать не мог

**Собрать и проверить.** Работа шла на Windows: macOS и Xcode на этой машине
нет, поэтому ни одна строка Swift не скомпилирована и не запущена. Код писался
консервативно и по документированным API, но **ошибки компиляции почти
наверняка есть** — это нормальная цена первой сборки, которую придётся
пройти на Mac. Считать написанное «готовым к выкладыванию» нельзя.

**Собрать движок туннеля.** AmneziaWG для iOS — это Go-библиотека, которую
надо собрать в `xcframework` на macOS. В `PacketTunnelProvider` мост к ней
вынесен в три метода (`startEngine`, `stopEngine`, `engineStatistics`) и
закрыт `#if canImport(AmneziaWG)`: без пакета проект собирается и честно
отказывается поднимать туннель, что позволяет отлаживать экраны и вход.

**Создать цели в Xcode-проекте.** Расширение туннеля — отдельная цель (target)
со своим bundle id, правами и профилем. Править `project.pbxproj` руками —
верный способ получить проект, который не открывается. Делается в Xcode за
пять минут, см. ниже.

## Что нужно сделать на Mac

### 1. Цели и зависимости

1. Открыть `ProstoVPN.xcodeproj`.
2. File → New → Target → **Network Extension**, тип **Packet Tunnel**,
   имя `ProstoVPNTunnel`, bundle id `cc.prostovpn.app.tunnel`.
3. Заменить сгенерированные файлы цели на готовые из `ProstoVPNTunnel/`.
4. Обеим целям прописать соответствующий `.entitlements`.
5. Добавить `PrivacyInfo.xcprivacy` в ресурсы **основной** цели.
6. File → Add Package Dependency → `https://github.com/amnezia-vpn/amneziawg-apple`,
   подключить к цели `ProstoVPNTunnel`.
7. В Build Settings основной цели завести пользовательскую настройку
   `PANEL_URL` = `https://prostovpn.cc` (её подхватывает `Info.plist`).

### 2. Учётная запись и права — тут есть блокеры

* **Apple Developer Program на организацию, а не на человека.** Требование
  Apple (App Review Guidelines 5.4): VPN-приложения публикуют только
  разработчики, зарегистрированные как организация. Индивидуальная учётная
  запись получит отказ независимо от качества кода. Нужен D-U-N-S номер на
  юридическое лицо, оформление занимает от нескольких дней до пары недель.
* **Право `packet-tunnel-provider`** запрашивается у Apple отдельно
  (Certificates, Identifiers & Profiles → App ID → Network Extensions).
  Без него приложение соберётся и установится, но профиль VPN не заведётся.
* **App Group** `group.cc.prostovpn` и **Keychain Sharing**
  `cc.prostovpn.shared` — завести в App ID обеих целей.

### 3. Обязательное для ревью

* **Политика конфиденциальности** — публичная ссылка. Есть:
  `https://prostovpn.cc/privacy`.
* **Раздел App Privacy** в App Store Connect заполнить так же, как
  `PrivacyInfo.xcprivacy`: идентификатор учётной записи, почта, объём
  трафика; отслеживания нет.
* **Экспортное соответствие.** VPN использует шифрование, поэтому
  `ITSAppUsesNonExemptEncryption` = `true`. Понадобится самоклассификация
  (обычно категория 5D992 по массовому рынку) и, для распространения во
  Франции, отдельная декларация.
* **Демонстрационная учётная запись** для ревьюера — логин и пароль
  рабочего аккаунта в поле «App Review Information». Без неё ревьюер видит
  экран входа и не может проверить приложение: отказ по 2.1.
* **Пояснение о сборе данных.** Guideline 5.1.1 требует прямо объяснить,
  зачем VPN собирает объём трафика. Формулировка: считается только суммарный
  объём за период для соблюдения лимита тарифа, история подключений не
  ведётся — узлы работают в оперативной памяти.
* **Скриншоты** 6.7" и 6.5", иконка 1024×1024 без прозрачности.

### 4. Проверить перед отправкой

- [ ] Приложение собирается на устройстве (не только в симуляторе:
      NetworkExtension в симуляторе не работает).
- [ ] Первое подключение показывает системный запрос на добавление VPN.
- [ ] Туннель переживает выгрузку приложения из многозадачности.
- [ ] Туннель поднимается после перезагрузки телефона.
- [ ] Смена страны переподключает без «залипания» в «подключается».
- [ ] При исчерпании трафика панель закрывает доступ, приложение это
      показывает и снимает туннель.
- [ ] Блокировка в панели разлогинивает приложение.
- [ ] Утечек нет: `https://browserleaks.com/ip` в Safari показывает страну
      узла и по IPv4, и по IPv6.
- [ ] Instruments → Animation Hitches: выезд шторки и переключение экранов
      без пропуска кадров.

## Про анимации

`LiquidGlass.swift` написан вокруг одного правила: **размытие и движение не
живут на одном слое**. Материал (`.ultraThinMaterial`, `.glassEffect`) — это
размытие фона под ним; пока слой неподвижен, система размывает один раз и
переиспользует. Стоит его двигать, масштабировать или менять прозрачность —
область размытия меняется каждый кадр, и весь фон пересчитывается заново,
шестьдесят раз в секунду.

Ровно на этом лагала веб-панель: полноэкранная подложка размывала таблицу на
сотню строк, пока выезжала шторка. Поэтому здесь:

* стекло стоит на месте, анимируется содержимое поверх него (`GlassReveal`);
* постоянные анимации — свечение и кольцо ожидания — рисуются в `Canvas` и
  не трогают раскладку, а `TimelineView(paused:)` останавливает отрисовку,
  когда анимация не видна;
* статичные многослойные композиции схлопываются в одну текстуру
  (`compositingGroup`, `drawingGroup`);
* всё движение снимается при включённой системной настройке «уменьшить
  движение».

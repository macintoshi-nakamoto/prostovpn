# Prosto VPN — iOS

Нативное SwiftUI-приложение для iPhone по hifi-референсу `design_handoff_prosto_vpn_ios`:
тёмная тема с оранжевыми акцентами, liquid-glass круглые кнопки, шрифт Manrope.

## Экраны

- **Вход** — логин/пароль (бэкенда аккаунтов пока нет, вход симулируется),
  поддерживается ключ доступа `vpn://` (Amnezia). Кнопка «Продолжить без входа»
  открывает экран подключения без логина и пароля — для тестов.
- **Подключение** — power-кнопка с conic-кольцом при подключении, статус и таймер,
  нижняя шторка выбора сервера (тап по ручке или перетаскивание пальцем).
- **Настройки** — раздельное туннелирование с файлами (.json/.txt, импорт через
  системный выбор файла, удаление долгим нажатием), Kill Switch, автозапуск,
  автоподключение, логирование, мгновенное переключение языка RU/EN, выход.
- **Поддержка** — Telegram, сайт, FAQ, оценка приложения.

## Сборка

Открыть `ProstoVPN.xcodeproj` в Xcode 15+, цель iOS 16.4+, iPhone only.
Подключение пока симулируется — интеграция NetworkExtension будет следующим этапом.

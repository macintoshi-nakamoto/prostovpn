# Панель Prosto VPN

Пользователи, серверы, подписки и деньги в одном месте. Плюс API, по
которому приложения входят по логину и паролю и получают свои ключи.

## Запуск за минуту

```bash
cd panel
python -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env          # поправь пароль администратора и секрет
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Панель на `http://localhost:8000`, вход — логин и пароль из `.env`.
Документация API сама себя описывает: `http://localhost:8000/docs`.

В Docker:

```bash
docker build -t prosto-panel . && docker run -p 8000:8000 -v prosto-data:/data prosto-panel
```

## Что уже умеет

* **Пользователи** — создание с логином и паролем, продление подписки,
  смена пароля, отключение доступа. Видно ключи, сессии и платежи каждого.
* **Серверы** — добавление, включение и выключение. Включённый сервер
  появляется у всех при следующем открытии приложения: раздавать вручную
  не надо.
* **Подписки** — продление добавляется к остатку, а не съедает его.
  Без действующей подписки приложение не получает ни одного сервера.
* **Деньги** — поступления и выручка за день, месяц и год, графики за
  30 дней и 12 месяцев.
* **Сессии** — с какой платформы и версии заходили, когда были активны,
  сколько человек онлайн.

## Два вида серверов

Сервер задаётся одним из двух способов — по тому, есть ли к нему доступ.

**Общий ключ.** Сервер не наш, root нет. В панель кладётся готовый конфиг
(ссылка `vpn://` или текст wg-quick), и его получают все. Работает сразу,
но отозвать доступ одному человеку нельзя — только всем.

**Своя генерация по SSH.** Сервер наш. Панель сама создаёт пару ключей,
выбирает свободный адрес, добавляет пира на сервер и убирает его, когда
подписка кончилась. Нужны доступ по SSH и шаблон конфига, где вместо
личных полей стоят `{private_key}` и `{address}`:

```
[Interface]
Address = {address}
PrivateKey = {private_key}
DNS = 1.1.1.1, 1.0.0.1
MTU = 1280
Jc = 4
Jmin = 230
Jmax = 649
S1 = 56
S2 = 149
H1 = 142296167-142319474
...

[Peer]
PublicKey = <публичный ключ сервера>
PresharedKey = <общий ключ>
AllowedIPs = 0.0.0.0/0, ::/0
Endpoint = 1.2.3.4:51820
```

Пир добавляется через `awg set`, поэтому чужие соединения не рвутся.

## API для приложений

```
POST /api/v1/login      {login, password, platform?, app_version?}
                        -> {token, expires_at, subscription, servers[]}
GET  /api/v1/servers    Authorization: Bearer <token>
                        -> {subscription, servers[]}
POST /api/v1/heartbeat  отметиться, пока подключён — из этого видно онлайн
POST /api/v1/logout     закрыть сессию
```

Каждый сервер приходит и текстом `config` (wg-quick — его понимает туннель),
и ссылкой `key` (`vpn://` — её понимает и наше приложение, и клиент Amnezia).

Токен хранится в базе только хэшем: утечка базы не отдаёт живые доступы.

## Проверки

```bash
.venv/bin/python -m pytest tests -q
```

23 проверки: пароли, генерация ключей, выдача адресов, разбор `vpn://`,
продление подписки, доступ без подписки, появление нового сервера у уже
заведённого пользователя, выручка по дням и месяцам, вход в админку и
отказ по поддельной cookie.

## Боевой запуск

* Поставь `PANEL_SECRET_KEY` — со значением по умолчанию cookie
  подделывается тривиально.
* Смени `PANEL_ADMIN_PASSWORD` до первого запуска: администратор
  создаётся один раз.
* Спрячь панель за HTTPS. Приложения ходят в неё с паролями
  пользователей, по http их видно целиком.
* Для боевой нагрузки поставь PostgreSQL:
  `PANEL_DATABASE_URL=postgresql+psycopg://user:pass@localhost/prosto`.

## Чего пока нет

* Автоматической выдачи после оплаты — платежи заносятся вручную. Поля
  под автоматику уже есть (`external_id`, `method`), нужен вебхук от
  платёжной системы.
* Учёта трафика по пользователям — понадобится опрос `awg show` на
  серверах.
* Автоматического отключения просроченных: доступ закрывается проверкой
  при выдаче серверов, но пир на сервере остаётся до нажатия «Отключить».

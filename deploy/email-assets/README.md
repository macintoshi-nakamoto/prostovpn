# Картинки для писем

Отсюда они уезжают на сервер в `/var/www/downloads/email/` и подключаются в
письмах абсолютными адресами `https://prostovpn.cc/downloads/email/<файл>`.

Относительные имена в письме не работают вовсе: почтовому клиенту не от чего
их отсчитывать. Вложения `cid:` работают, но половина клиентов показывает их
скрепкой рядом с письмом — выглядит так, будто мы прислали файлы.

## Почему они такие маленькие

Исходники из макета весили 1,5 МБ на три письма: чек 1320 пикселей в ширину
при выводе в 82. Здесь всё пережато под двойную плотность экрана — 73 КБ на
всё. Письмо тянут по мобильному интернету, и лишний мегабайт это секунды
ожидания и повод для почтовика обрезать картинки.

| Файл | Показывается | Хранится |
|---|---|---|
| `logo-white.png` | 150px | 300px |
| `receipt-3d.png` | 82px | 164px |
| `clock-3d.png` | 92px | 184px |
| `lock-3d.png` | 72px | 144px |
| `tg-icon.png` | 20px | 40px |
| `pattern-pixels.png` | плитка фона | 48×48, как есть |

## Обновить на сервере

```bash
scp deploy/email-assets/*.png root@45.151.106.253:/var/www/downloads/email/
ssh root@45.151.106.253 'chown www-data:www-data /var/www/downloads/email/*.png'
```

Имена менять нельзя: они зашиты в шаблоны `backend/app/emails/*.html`.

# Боевые конфиги сервера

Снимок того, что реально стоит на 45.151.106.253 на 18 августа 2026. Лежит
здесь ради одного: до сих пор эти файлы существовали только на сервере, и
восстановить машину по репозиторию было нельзя.

Это **снимок, а не источник правды**: правки по-прежнему делаются на сервере,
а сюда их надо переносить руками. Если файлы разойдутся — верным считается
сервер.

| Файл | Где лежит на сервере |
|---|---|
| `nginx-prosto-panel.conf` | `/etc/nginx/sites-available/prosto-panel` |
| `prosto-limits.conf` | `/etc/nginx/conf.d/prosto-limits.conf` |
| `prosto-panel.service` | `/etc/systemd/system/prosto-panel.service` |
| `prosto-bot.service` | `/etc/systemd/system/prosto-bot.service` |
| `prosto-extra-ports.service` | `/etc/systemd/system/prosto-extra-ports.service` |

Секретов здесь нет и быть не должно: и панель, и бот берут их из своих
`.env` (`/opt/prosto-vpn/backend/.env`, `/opt/prosto-bot/.env`), а те в
репозиторий не попадают — есть только `.env.example`.

## Чего здесь нет

**Сертификаты Let's Encrypt** (`/etc/letsencrypt/live/prostovpn.cc/`) — их
выпускает certbot, хранить копию незачем и небезопасно.

**Конфигурация самого AmneziaWG** (`/etc/amnezia/amneziawg/awg0.conf`)
содержит приватный ключ узла и список пиров. Пиры панель раздаёт сама, а
приватный ключ узла — это и есть весь VPN: утечёт он, и трафик всех
клиентов расшифровывается. В репозиторий он не поедет никогда. Как поднять
узел с нуля — `deploy/setup-awg.sh`.

**Видео для бота** (`/opt/prosto-bot/assets/*.mp4`, 82 МБ) — это медиа, а не
исходники. Git хранит бинарники целиком на каждую версию, и один такой
коммит навсегда добавляет к весу репозитория десятки мегабайт у каждого, кто
его склонирует. Файлы лежат на сервере; если нужна их история — им место в
объектном хранилище или в git-lfs, и это отдельное осознанное решение.

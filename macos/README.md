# Prosto VPN — macOS

Нативное SwiftUI-приложение для Mac. Тёмная тёплая тема с оранжевым
акцентом, шрифт Manrope, круглые кнопки на Liquid Glass — то же лицо, что
у сборок для iOS и Android.

Подключение настоящее: туннель AmneziaWG поднимается на реальном utun,
маршруты и DNS переключаются по-честному. Никакой симуляции.

## Что внутри

```
macos/
├── ProstoVPN/        приложение (SwiftUI, macOS 13+)
├── Helper/           привилегированная служба (запускается от root)
├── Shared/           разбор wg-quick и протокол между ними
├── Engine/           сборка движка AmneziaWG (Go)
└── scripts/          установка службы и сборка DMG
```

### Паритет с Android

Приложение для Android — эталон функциональности, и Mac повторяет его целиком:

| | Android | macOS |
|---|---|---|
| вход по логину с `device_id` | да | да |
| ключ `vpn://` без панели | да | да, плюс открытие ссылкой |
| опрос подписки раз в минуту | да | да |
| объяснение пустого списка стран (`notice`) | да | да |
| предупреждение о трафике и сроке, кнопка «Продлить» | да | да |
| выход по решению панели с объяснением | да | да |
| обновление из приложения с проверкой sha256 | APK | DMG |
| обязательное обновление баннером на главном | да | да |
| раздельное туннелирование со своими списками | да | да |
| сообщения системы о состоянии | постоянное уведомление | уведомления + строка меню |

Разное — только там, где платформы разные. На Android постоянное уведомление
держит процесс живым: оболочки Huawei и Xiaomi иначе выгружают приложение и
рвут туннель. На Mac процесс никто не убивает, туннель держит служба, поэтому
постоянного уведомления нет — вместо него значок в строке меню, а уведомления
остаются для того, что случилось без участия человека: связь оборвалась,
устройство отвязали в кабинете, кончается трафик или вышло обязательное
обновление.

### Почему служба, а не Network Extension

Поднять `utun`, переписать таблицу маршрутов и подменить DNS может только
root. У приложения таких прав нет и быть не должно. Есть два пути:

* **NetworkExtension** — красиво, но требует платного участия в Apple
  Developer Program и профиля с правом `packet-tunnel-provider`. Без него
  расширение просто не загрузится ни у кого.
* **Привилегированная служба** — маленький демон под launchd, которому
  приложение шлёт три команды. Один раз спрашивает пароль администратора и
  работает у всех, включая сборки вне App Store. Так же устроен настольный
  клиент Amnezia.

Выбран второй. Служба не выполняет ничего из конфигурации сервера: она
разбирает wg-quick сама и вызывает только `ifconfig`, `route` и
`networksetup` по абсолютным путям. Иначе сервер, приславший конфиг,
получал бы root на машине пользователя.

### Как поднимается туннель

1. Приложение отдаёт службе wg-quick целиком.
2. Служба разрешает адрес сервера **до** поднятия интерфейса — потом DNS
   может уже не ответить.
3. Запускает движок `prostovpn-awg` своим дочерним процессом (`-f`), тот
   создаёт `utunN` и открывает управляющий сокет в `/var/run/amneziawg`.
4. Конфигурация уходит в движок по UAPI: ключи переводятся из base64 в hex,
   поля обфускации (`Jc`, `Jmin`, `S1`, `H1`…) передаются как есть.
5. Прописывается адрес, MTU, маршрут до сервера в обход туннеля и две
   половины `/1` вместо `0.0.0.0/0` — так системный маршрут по умолчанию
   остаётся на месте и не требует восстановления.
6. DNS из конфига подменяет системный; прежние резолверы сохраняются на
   диск, чтобы вернуться даже после падения службы.

Подключённым приложение считает туннель только после рукопожатия. Поднятый
`utun` сам по себе ничего не значит: он поднимается и когда сервер молчит,
и тогда весь трафик уходит в никуда. Не дождавшись рукопожатия за 20
секунд, приложение снимает туннель и говорит об этом.

### Раздельное туннелирование

Российские сети идут напрямую, мимо VPN: Госуслуги и ЕСИА отвечают только
с местных адресов, банки требуют подтверждений, школьные порталы просто не
открываются. Всё остальное остаётся в туннеле.

Список — тот же файл, что у Android (`ru-split-tunnel.json`, 8629 сетей),
он лежит в ресурсах приложения. Формат общий, поэтому один файл работает на
обеих платформах:

```json
[{"hostname": "2.56.24.0/22", "ip": ""}, ...]
```

Принимаются также простой массив строк и текстовый файл по одной сети на
строку — списки приносят в том виде, в каком нашли. Свой файл добавляется
в «Настройки» → «Список сетей»; активен всегда ровно один, встроенный
удалить нельзя.

К любому выбранному списку **всегда** добавляются сети Госуслуг и порталов
Московской области (`macos/Shared/BypassRoutes.swift`): человек может
подсунуть свой файл, где их нет, и молча потерять вход в ЕСИА.

Сетями, а не адресами: у CDN Госуслуг адреса ротируются, и привязка к
конкретному IP отвалилась бы через день.

**Маршруты пишутся прямо в ядро.** Восемь с половиной тысяч вызовов
`/sbin/route` — это полторы миллисекунды на каждый, то есть около
тринадцати секунд на подключение и столько же на отключение. Хелпер
открывает `PF_ROUTE` и пишет сообщения сам (`Helper/RouteSocket.swift`) —
весь список применяется за доли секунды.

Выход в интернет запоминается снимком **до** поднятия туннеля. Спросить
маршрут по умолчанию позже — значит получить в ответ собственный `utun` и
закольцевать ровно то, что собирались пустить мимо.

Оговорка про DNS: при включённом «DNS из конфига» имена резолвятся через
туннель. Для сетей из списка это безразлично — трафик всё равно уходит
напрямую, — но сервис с геозависимым DNS может вернуть адрес вне списка, и
тогда он пойдёт через VPN.

### Kill Switch

Если движок умирает сам, маршруты по умолчанию заменяются на blackhole:
трафик обрывается, а не утекает мимо туннеля. Снимается по «Отключить».

## Сборка

Готовый образ — одной командой:

```bash
cd macos
./scripts/make-dmg.sh
```

Получается `dist/ProstoVPN-<версия>.dmg`: приложение universal (arm64 +
x86_64), подписанное ad-hoc, рядом ярлык «Программы» и короткая инструкция.
В конце скрипт печатает размер и sha256 — их же ждёт панель при публикации
релиза.

С сертификатом Apple образ подписывается по-настоящему:

```bash
SIGN_IDENTITY="Developer ID Application: …" ./scripts/make-dmg.sh
xcrun notarytool submit dist/ProstoVPN-1.0.0.dmg --keychain-profile prosto --wait
xcrun stapler staple dist/ProstoVPN-1.0.0.dmg
```

Разработка — как обычно:

```bash
./Engine/build.sh          # только если бинарника Engine/bin ещё нет
open ProstoVPN.xcodeproj   # Xcode 26, схема ProstoVPN
```

**Собирать нужно вне синхронизируемых папок.** Каталог проекта лежит на
Рабочем столе, а Рабочий стол синхронизирует iCloud Drive: файловый провайдер
вешает на свежий `.app` атрибут `com.apple.FinderInfo`, и codesign отказывает —
«resource fork, Finder information, or similar detritus not allowed». Поэтому
`make-dmg.sh` собирает в `~/Library/Caches/ProstoVPN-build`; при ручном запуске
`xcodebuild` задавайте `-derivedDataPath` туда же.

Движок собирается universal (arm64 + x86_64) и лежит в репозитории, чтобы
приложение собиралось на машине без Go. Исходники движка скрипт клонирует
сам в `Engine/src` и в репозиторий не кладёт.

## Служба

Ставится из приложения: «Настройки» → «Служба подключения» → «Установить»,
либо автоматически при первом подключении. Один раз спрашивается пароль
администратора.

Руками:

```bash
sudo ./scripts/install-helper.sh \
    build/dd/Build/Products/Debug/com.prostovpn.helper \
    Engine/bin/prostovpn-awg \
    scripts/com.prostovpn.helper.plist \
    $(id -u)
```

Удалить вместе с маршрутами и DNS:

```bash
sudo ./scripts/uninstall-helper.sh
```

Служба слушает `/var/run/prostovpn-helper.sock` и принимает команды только
от того, кто её поставил (uid проверяется через `LOCAL_PEERCRED`), либо от
root.

## Вход

Два способа, как и на телефоне:

* **Логин и пароль** — приложение идёт в панель (`panel/`) по
  `POST /api/v1/login` и получает токен и список серверов. Адрес панели
  зашит в сборку: `AppState.defaultPanelAddress`. В настройках его нет
  намеренно — поле, которым пользуются раз в жизни, только путает, а
  ошибка в нём выглядит как «приложение не работает».
* **Ключ доступа** — `vpn://…` от Amnezia или просто текст wg-quick.
  Работает без панели и без подписки. Ключ можно и открыть ссылкой:
  приложение зарегистрировано на схему `vpn://`.

Показать или скопировать выданный ключ из приложения нельзя: конфигурация
сервера — это доступ, который расходится по чужим устройствам ровно так же
легко, как копируется.

## Интерфейс

Стекло — системное Liquid Glass из macOS 26 (`glassEffect`), без самодельных
имитаций: у настоящего стекла своя реакция на курсор и нажатие, и подменять
её масштабированием значит сразу выдавать подделку. Карточка сервера и
шторка выбора живут в одной `GlassEffectContainer` с общим `glassEffectID`,
поэтому шторка не появляется поверх экрана, а вырастает из карточки —
то же стекло меняет форму. Закрывается перетаскиванием вниз, клавишей Esc
или щелчком по затемнению.

На macOS 13–15 стекла нет: там материал с обводкой, а шторка честно выезжает
снизу.

Токен и конфигурации серверов лежат в связке ключей, а не в UserDefaults:
это доступ к VPN, а не настройки внешнего вида.

## Обновления

Приложение спрашивает панель (`/api/v1/version?platform=macos`) при запуске и
при заходе в настройки. Новая версия скачивается образом, сверяется с
обещанными панелью размером и sha256 — и только потом ставится: подменить
установщик по дороге может ровно тот, кто уберёт и хеш, а ссылка без `https`
не принимается вовсе.

Заменить `.app`, пока он выполняется, нельзя, поэтому последний шаг делает
короткий скрипт: дожидается выхода приложения, копирует новую версию на место
старой, снимает карантин и запускает её. Туннель при этом не рвётся — его
держит служба, а не окно. Если приложение лежит там, куда пользователю писать
нельзя, вместо подмены открывается смонтированный образ.

## Чего пока нет

* **Нотаризации.** Сборка подписывается ad-hoc, поэтому при первом запуске
  система спросит подтверждение (в образе есть инструкция). Для тихой
  установки нужен Developer ID и `notarytool` — см. «Сборка».

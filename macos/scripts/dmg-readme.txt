Prosto VPN для macOS
====================

1. Перетащите «ProstoVPN» в папку «Программы» (значок рядом).
2. Откройте приложение из «Программ».

Если macOS говорит, что «автор является неустановленным разработчиком»
или что не может подтвердить отсутствие вредоносного ПО, — сборка не
нотаризована у Apple, это не поломка. Делается один раз:

  macOS 15 и новее: нажмите «OK», откройте Системные настройки →
  «Конфиденциальность и безопасность», прокрутите вниз — там появится
  строка про ProstoVPN и кнопка «Открыть всё равно». Нажмите её и
  подтвердите паролем. Если то же самое спросили про образ .dmg —
  повторите для него.

  macOS 14 и старше: щёлкните по приложению правой кнопкой → «Открыть»
  → «Открыть».

  Через Терминал (любая версия), одна строка:

    xattr -dr com.apple.quarantine /Applications/ProstoVPN.app

После этого приложение открывается обычным двойным щелчком, а обновления
ставятся уже без вопросов.

При первом подключении приложение один раз попросит пароль
администратора: без прав root нельзя поднять сетевой интерфейс,
переписать маршруты и подменить DNS. Пароль уходит только системному
диалогу macOS — приложение его не видит.

Windows

Скачайте установщик и запустите. Windows может спросить подтверждение — это обычное предупреждение для программ, работающих с сетевым подключением.

Android

Скачайте файл и откройте его. Понадобится разрешить установку из этого источника — система подскажет, где нажать.

iPhone и iPad

Установите приложение и разрешите добавление конфигурации — iOS спросит об этом один раз при первом подключении.

macOS

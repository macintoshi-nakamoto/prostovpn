# Prosto VPN — Windows

Десктопный клиент Prosto VPN на Compose Desktop: тот же дизайн и тот же
liquid glass, что в iOS/Android-клиентах (Skia исполняет тот же SkSL-шейдер
преломления). Компактное безрамочное окно 400×640 со скруглёнными углами,
перетаскиванием за любое пустое место и своими кнопками свернуть/закрыть.

Вход по ключу `vpn://…` (Амнезия) с определением сервера и **реальным
подключением**: приложение разбирает ключ в конфиг AmneziaWG и поднимает
туннель через `amneziawg.exe /installtunnelservice`.

## Как работает подключение

`amneziawg.exe` (форк wireguard-windows, MIT) и `wintun.dll` кладутся в
установщик рядом с приложением. По нажатию кнопки питания приложение:

1. собирает `%LOCALAPPDATA%\ProstoVPN\prostovpn.conf` из ключа —
   с учётом раздельного туннелирования (`AllowedIPs` считается как дополнение
   к списку исключений);
2. запускает `amneziawg.exe /installtunnelservice <conf>` **с правами
   администратора** (UAC), это создаёт службу `AmneziaWGTunnel$prostovpn`;
3. ждёт, пока служба перейдёт в состояние Running, и включает таймер.

Отключение — `/uninstalltunnelservice prostovpn`.

**Что нужно знать:**
- Windows покажет запрос UAC при каждом подключении: создание службы и
  установка драйвера Wintun требуют прав администратора. Учётная запись
  должна входить в группу «Администраторы».
- Гостевой режим и демо-серверы подключение не выполняют — нужен ключ.
- Бинарники не лежат в репозитории, их скачивает `fetchTunnelBinaries`
  с проверкой SHA-256 (см. THIRD_PARTY_LICENSES.md).

## Сборка

Установщик Windows (MSI + EXE) собирается на Windows (нужен JDK 17+):

```bat
cd windows
gradlew.bat packageMsi packageExe
```

Задача сама скачает движок туннеля (`amneziawg.exe`, `wintun.dll`)
и проверит контрольные суммы.

Готовые файлы: `build/compose/binaries/main/msi/` и `.../exe/`.

Либо через GitHub Actions: workflow **windows-desktop** собирает установщики
на каждом пуше в `main`, затрагивающем `windows/` (артефакты — на странице
запуска workflow).

Запуск из исходников на любой ОС:

```
./gradlew run
```

## Обновление поверх установленной версии

Версия установщика собирается как `1.0.<число коммитов>`, поэтому каждая
новая сборка ставится поверх предыдущей штатным обновлением. Если MSI всё
же говорит «Another version of this product is already installed» —
значит версия совпала с уже установленной: удалите «Prosto VPN» через
«Установка и удаление программ» и поставьте заново.

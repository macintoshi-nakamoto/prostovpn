# Prosto VPN — Windows

Десктопный клиент Prosto VPN на Compose Desktop: тот же дизайн и тот же
liquid glass, что в iOS/Android-клиентах (Skia исполняет тот же SkSL-шейдер
преломления). Компактное безрамочное окно 400×640 со скруглёнными углами,
перетаскиванием за любое пустое место и своими кнопками свернуть/закрыть.

Вход по ключу `vpn://…` (Амнезия) с определением сервера и **реальным
подключением**: приложение разбирает ключ в конфиг AmneziaWG и поднимает
туннель своим движком.

## Как работает подключение

Движок туннеля — наш собственный `prostovpn-tunnel.exe` (исходники в
`windows/tunnel`, сборка на Go). Установленный клиент Amnezia не нужен и не
используется: движок сам поднимает адаптер Wintun, работает службой Windows
и ведёт журнал. По нажатию кнопки питания приложение:

1. собирает `%LOCALAPPDATA%\ProstoVPN\prostovpn.conf` из ключа —
   с учётом раздельного туннелирования (`AllowedIPs` считается как дополнение
   к списку исключений);
2. запускает `prostovpn-tunnel.exe /installtunnelservice <conf> <отчёт>`
   **с правами администратора** (UAC) — создаётся служба
   `ProstoVPNTunnel$prostovpn`;
3. опрашивает `/status prostovpn`, пока служба не перейдёт в Running.

Отключение идёт **без UAC**: приложение выставляет событие
`Global\ProstoVPN-Tunnel-Stop`, служба видит его и останавливает себя сама.
Остановленную службу удаляет следующее подключение. Если событие не
сработало, приложение снимает службу через `/uninstalltunnelservice` с
повышением прав.

**Что нужно знать:**
- Запрос UAC появляется один раз — на подключение: создать службу и
  загрузить драйвер Wintun обычный пользователь не может. Учётная запись
  должна входить в группу «Администраторы».
- Гостевой режим и демо-серверы подключение не выполняют — нужен ключ.
- Движок собирается из исходников задачей `buildTunnel` (нужен Go 1.24+),
  wintun.dll скачивает `fetchWintun` с проверкой SHA-256
  (см. THIRD_PARTY_LICENSES.md).

## Если подключение не удалось

Приложение показывает причину на экране, а подробности оставляет в
`%LOCALAPPDATA%\ProstoVPN`:

- `install.log` — что делал повышенный процесс: разбор конфига, создание
  и запуск службы, итог;
- `tunnel.log` — журнал самого туннеля, его выкладывает служба при
  остановке (рукопожатия, маршруты, ошибки драйвера).

## Сборка

Установщик Windows (MSI + EXE) собирается на Windows (нужен JDK 17+
и Go 1.24+):

```bat
cd windows
gradlew.bat packageMsi packageExe
```

Задачи сами соберут движок туннеля (`prostovpn-tunnel.exe`) и скачают
`wintun.dll` с проверкой контрольной суммы.

Готовые файлы: `build/compose/binaries/main/msi/` и `.../exe/`.

Либо через GitHub Actions: workflow **windows-desktop** собирает установщики
на каждом пуше в `main`, затрагивающем `windows/` (артефакты — на странице
запуска workflow).

Запуск из исходников на любой ОС:

```
./gradlew run
```

## Обновление поверх установленной версии

Версия установщика собирается как `1.0.<число коммитов>`, поэтому каждая
новая сборка ставится поверх предыдущей штатным обновлением. Если MSI всё
же говорит «Another version of this product is already installed» —
значит версия совпала с уже установленной: удалите «Prosto VPN» через
«Установка и удаление программ» и поставьте заново.

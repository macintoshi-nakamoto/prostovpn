# Движок туннеля Prosto VPN

`prostovpn-tunnel.exe` — собственный бэкенд VPN, который поднимает туннель
внутри нашего приложения. Отдельно установленный клиент Amnezia не нужен:
движок сам создаёт адаптер Wintun, настраивает адреса, маршруты, DNS и
правила брандмауэра, работает службой Windows и ведёт журнал.

## Команды

| Команда | Права | Что делает |
| --- | --- | --- |
| `/installtunnelservice <conf> [отчёт]` | администратор | снимает прошлую службу, создаёт `ProstoVPNTunnel$<имя>` и запускает её; пишет пошаговый отчёт |
| `/uninstalltunnelservice <имя>` | администратор | останавливает и удаляет службу |
| `/stop <имя>` | пользователь | просит службу остановиться самой — без UAC |
| `/status <имя>` | пользователь | `RUNNING` / `STARTING` / `STOPPING` / `STOPPED` / `ABSENT` |
| `/service <conf>` | — | тело службы, запускает диспетчер служб |

Имя туннеля берётся из имени conf-файла без расширения.

## Отключение без запроса прав

Служба создаёт событие `Global\ProstoVPN-Tunnel-Stop` с правом «выставить»
для интерактивного пользователя. `/stop` выставляет событие, служба видит
его и останавливает себя сама — второй запрос UAC не нужен. Остановленную
службу удаляет следующее `/installtunnelservice`.

## Журналы

Кольцевой журнал движка лежит в `%ProgramFiles%\ProstoVPN\Data\log.bin`,
куда пускают только SYSTEM и администраторов. Поэтому при остановке служба
выкладывает читаемую копию в `tunnel.log` рядом с конфигурацией — оттуда её
читает приложение.

## Сборка

```
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -ldflags "-s -w -H=windowsgui" -trimpath -o prostovpn-tunnel.exe .
```

Или `gradlew buildTunnel` из каталога `windows` — тот же вызов, результат
кладётся в `windows/resources/windows/`, откуда его забирает установщик.

Ресурс версии (`resource_windows_amd64.syso`) собран из `versioninfo.json`
утилитой `goversioninfo`; благодаря ему запрос UAC подписан «Prosto VPN
Tunnel», а не именем файла.

## Происхождение кода

`internal/` — доработанный код `wireguard-windows` / `amneziawg-windows`
(MIT): служба, настройка интерфейса, брандмауэр, разбор конфигурации.
Протокол исполняет библиотека `amneziawg-go` (MIT). Изменения относительно
оригинала: свои имена службы, каналов и каталога данных, собственный запуск
и остановка, выгрузка журнала наружу. Подробности — в
`THIRD_PARTY_LICENSES.md` в корне репозитория.
